# TrayCoordinateHelper

C# 6 / .NET Framework 4.7.2 Windows Forms 예제입니다.

## 실행

1. Visual Studio에서 `TrayCoordinateHelper_ver1/TrayCoordinateHelper.sln`을 엽니다.
2. .NET 데스크톱 개발 도구와 .NET Framework 4.7.2 대상 팩을 설치합니다.
3. F5로 실행합니다. 프로토콜 분석 화면이 최대화되어 열립니다. 트레이 설정은 상단 탭에서 엽니다.

## 프로토콜 분석

주소 열과 HEX 바이트를 원본 입력란에 붙여넣고 **분석 · 새 기록 저장**을 누릅니다.

```text
0000 FF FF FF FF 30 01 00 00 02 00 00 00 06 00 00 00
0010 24 00 00 00
```

- A열: 1부터 시작하는 번호
- B열: 자유 메모. 셀을 더블클릭하거나 F2로 편집하고 Enter/다른 셀로 확정하면 자동 저장합니다.
- C열: 원본 HEX (읽기 전용)
- D열: 해석값 (읽기 전용)
- 기본 해석은 4바이트 Little-endian UInt32입니다. Int32를 선택하고 분석하면 음수를 포함한 새 기록이 만들어집니다.
- 첫 `FF FF FF FF`부터 해석합니다. Prefix도 정수 행으로 표시됩니다. 부족한 마지막 바이트는 HEX로 보존하고 해석값을 `—`로 표시합니다.
- 결과를 선택하고 Ctrl+C로 복사할 수 있습니다. 메모 한 셀에 텍스트 붙여넣기도 가능합니다.
- 기록 이름은 상단 입력란에서 바꿉니다. 별 버튼으로 상단 고정/해제합니다. 고정된 기록부터, 같은 그룹에서는 최신 기록부터 표시됩니다.
- 왼쪽 목록을 선택하면 원본, 메모, 해석값, 당시 해석 설정을 복원합니다. 새 분석은 기존 기록을 덮어쓰지 않습니다.
- 원본을 수정하면 표를 비우고 새 분석을 준비합니다. 아직 분석하지 않은 입력은 저장하지 않습니다.
- 목록/본문 경계, 원본/표 경계, 표의 열 경계를 드래그하여 크기를 조절할 수 있습니다.

## 저장 위치

`%LOCALAPPDATA%\TrayCoordinateHelper\ProtocolHistory`

각 분석을 XML 파일로 저장하며, 원본의 줄바꿈도 보존합니다. 메모, 이름, 상단 고정, 생성 시각, 해석 설정 및 결과가 포함됩니다. 저장 시 직전 버전을 `.bak`으로 남깁니다. 손상된 기록은 가능한 경우 백업을 읽고 안내합니다. 저장 실패 시 상태 메시지가 표시되며, 저장에 실패한 편집을 남긴 채 창을 닫지 않습니다.

기록은 사용자 PC에 저장되며 Git 대상에 포함되지 않습니다. 다른 PC로 옮기려면 앱을 종료하고 이 폴더를 복사합니다. 여러 프로그램 인스턴스에서 동일 기록을 동시에 편집하는 용도는 지원하지 않습니다.

## 코드 역할

- `ProtocolPanel.cs`: 표, 기록 선택, 메모 편집, 자동 저장 이벤트
- `ProtocolPanel.Designer.cs` / `.resx`: Visual Studio 디자이너 화면
- `ProtocolHistory.cs`: 화면과 독립적인 분석 기록 모델 및 XML 저장소
- `PacketConverter.cs`: 주소/HEX 입력 검증과 Little-endian 변환
- `Program.cs`: 확대된 실행 창과 프로토콜/트레이 탭

고정 항목명 설명은 결과에서 사용하지 않습니다. 메모는 사용자가 상황에 맞게 작성합니다. 현재 입력 형식은 주소+HEX 텍스트이며, ASCII 열, pcap 직접 읽기, 실시간 UDP 수신, 장비별 혼합 자료형, 송수신 자동 대조는 구현하지 않았습니다.

## 검증

`TrayCoordinateHelper_ver1/ProtocolHistoryVerification.cs`는 앱 프로젝트와 별도의 검증 프로그램입니다. C# 컴파일러로 앱 EXE, System.Windows.Forms, System.Drawing을 참조해 빌드합니다. 원본/메모 저장과 복구, 음수 해석, 바이트 부족, 이름 변경, 고정 순서, 종료 직전 셀 편집 저장, 재실행 및 화면 크기를 검증합니다. 테스트 데이터는 `.test-output`에 격리됩니다.
